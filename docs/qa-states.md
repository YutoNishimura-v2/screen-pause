# 初回の制限と例外時の表示

デモは初回の制限プレビューまで **3タップ**。「許可してアプリを選ぶ」「今から1時間の制限を始める」「制限画面のプレビュー」の順に押す。XCTest はタップ数と起動後の所要時間を記録し、60秒未満を検査する。

| 状態 | 変更前 | 変更後 |
| --- | --- | --- |
| 初回の案内 | 設定手順を説明 | スクリーンタイムとの違いを1文で説明 |
| 初回の制限 | 対象を選んでから時間設定画面に移動 | 対象選択画面で制限を開始。予定はホームで編集できる |
| 許可の拒否 | 再試行を案内 | 許可されていない理由と「設定を開く」「許可を再試行」 |
| 起動時に保存済みの許可が未決定 | 起動直後に取り消しと判定していた | 先に許可を再確認し、承認済みなら保存済みの対象・予定でホームを開く |
| 許可の取り消し | 復旧時は対象の再選択が必要 | 取り消しを一文で表示し、設定または再試行を案内。再許可後に対象を選び直すと元の予定を適用 |
| 保護者による制限 | 一般的なエラー | 保護者に設定の確認を頼む案内と「許可を再試行」 |
| 選択が空 | 画面が進まないか保存が無効 | アプリかカテゴリを1つ以上選ぶまで、選択画面の開始ボタンは無効 |
| 最初の制限の保存に失敗 | 選択画面を閉じてホームの手前に戻る | 選択画面と対象を保持し、開始ボタンの上に再試行の案内を表示 |
| 初日のレポート | 比較値に「—」 | 利用時間が表示される条件と今日の回数を表示。記録済みの0分と「記録待ち」を区別 |
| シールド | 停止操作の名称が抽象的。待機中は拡張機能が応答を保留 | 主ボタンは「開かずに戻る」。開く操作を押すと待機が始まり、指定秒数が経過した後の再押下で解除。0秒は初回押下で解除 |
| 読み上げと最大文字サイズ | プレビューの開く操作はテキスト | 両操作がボタンとして読まれる。回数は意味と単位をまとめて読み上げる。プレビューはAX5でスクロールできる構成 |
| 待機0秒・30秒 | 通常と中間値のテスト | 両端で解除できる時刻、厳格モード、待機要求の失効を検査 |
| 制限中にJSTの午前0時を通過 | 別々に日付変更と日またぎを検査 | 同じ制限を維持したまま今日の回数が0に戻り、次の停止で1になることを検査 |
| 予定のある日を1日欠く | 連続日数だけ検査 | 今日の停止回数と連続日数を併せて検査。次の達成日は1日目 |
| Pro専用の待機中にProが失効 | 契約の期限と解除を個別に検査 | 基本の制限を維持。失効前の待機要求を無効にし、新しい要求は標準の10秒で解除できることを検査 |

## CIの撮影

ライト・ダークで各7枚、合計14枚を公開する。

- `01-onboarding-permission` と `02-onboarding-apps` は初回案内と対象選択。
- `04-home`、`05-shield-preview`、`06-report` は初日の回数、制限画面のプレビュー、無料の利用時間レポート。
- `07-paywall` は購入条件、`08-paywall-value` は価格より先に表示する週比較と連続日数。

## 実機確認

- 新規起動の最初の画面から計時する。許可してアプリを1つ選び、「今から1時間の制限を始める」を押す。ホーム画面かアプリスイッチャーから対象を開き、OSの許可・認証・アプリ選択も含めて実際のシールド表示まで60秒以内か記録する。
- 許可を拒否、取り消し、または保護者が制限した状態で案内を確認する。拒否・取り消し時は「設定を開く」からiOSが管理するアプリの設定に進む。スクリーンタイム側の権限一覧に移動できるかと、再許可後に選び直して制限が戻るかを確認する。保護者による制限時は、保護者への案内と再試行を確認する。
- StoreKit が月額だけを返した場合、価格を取得できたプランから購入操作へ進めることを確認する。再読み込みで年額が取得できた場合は、年額を選ぶと対応する価格と無料体験の条件が出ることを確認する。
- 制限を保存した端末でアプリを終了して開き直し、保存済みの対象と予定でホームを開けることを確認する。再起動直後に許可が未決定と報告された場合も、承認が戻れば選び直しは不要。
- 小型iPhoneで文字サイズをAX5にし、VoiceOverで実際のシールドの主・副ボタンを読む。欠けや重なりがなく、30秒より前は開かず、経過後の再押下で開けるかを確認する。iOSが描画するシールドの文字拡大と読み上げ順は実機確認待ち。

この作業環境ではSwiftとiOSが利用できないため、デモの実行時間、実機の初回ブロックと各画面の表示は未計測。Nodeの境界テストは既存のJavaScriptモデルとSwiftソースへの参照で検査し、Swiftの実行はXCTestと実機で確認する。
