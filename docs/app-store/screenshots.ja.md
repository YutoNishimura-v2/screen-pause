# App Store掲載用スクリーンショット

撮影名はライト・ダーク共通です。上から掲載順に並べています。

| 撮影名 | キャプション |
| --- | --- |
| `05-shield-preview` | 開く前に、10秒のひと呼吸 |
| `02-onboarding-apps` | 選んだアプリに、1時間の制限を設定 |
| `04-home` | 今日、開かずに戻れた回数 |
| `06-report` | よく使うアプリと時間帯がわかる |
| `08-paywall-value` | Proで、開かずに戻れた日を振り返る |

1枚目は見出しと制限画面の「開かずに戻る」「10秒の待機を始める」を読める大きさで組み合わせます。10秒は標準設定の待ち時間です。

掲載用の撮影では、2枚目にアプリを選ぶ操作、3枚目に「開かずに戻る」を試した直後の回数、4枚目にアプリ別・時間帯別の内訳、5枚目にProの月間カレンダーを写します。例として撮影した記録には「表示例」と添えます。撮影名は現行の識別名です。
