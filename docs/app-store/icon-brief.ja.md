# ひと呼吸のアプリアイコン制作要件

ホーム画面で「開く前にひと呼吸おく」ことが伝わるアイコン。中央にシンプルな一時停止の形を置き、小さく表示しても2本の形と間の余白が分かるようにする。文字、数字、細い輪郭、装飾は省く。iOS標準のスクリーンタイムと見分けられるシルエットにする。

1024 × 1024 pxの不透明なPNGを納品する。角丸はiOSがかけるため、書き出しは正方形にする。ホーム画面の実寸とApp Storeの一覧で候補を並べ、判読性を確認して選ぶ。採用した素材は `App/Assets.xcassets/AppIcon.appiconset` に登録し、アーカイブで確認する。 [Appleのアプリアイコン仕様](https://developer.apple.com/design/human-interface-guidelines/app-icons)
