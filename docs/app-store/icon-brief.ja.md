# ひと呼吸の App Store アイコン

ホーム画面で「開く前にひと呼吸おく」ことが伝わるアイコン。中央にシンプルな一時停止の形を置き、小さく表示しても2本の形と間の余白が分かるようにする。文字、数字、細い輪郭、装飾は省く。iOS標準のスクリーンタイムと見分けられるシルエットにする。

2026年11月27日に、ひと目で意味が伝わる案 A「ひと呼吸の柱」を採用。App Store の掲載アイコンには本体と同じ、1024 × 1024 px の正方形の不透明 PNG を使います。 [掲載用 PNG](../../App/Assets.xcassets/AppIcon.appiconset/AppIcon.png)

iOS 18 以降のホーム画面には、ダークと色合い調整の画像も登録しています。各画像を 60 px と 120 px で確認できます。 [ホーム画面のアイコンプレビュー](../preview/app-icon.png) · [Apple のアプリアイコン仕様](https://developer.apple.com/design/human-interface-guidelines/app-icons)
