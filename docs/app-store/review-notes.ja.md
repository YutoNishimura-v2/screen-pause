# App Review 審査メモ

「ひと呼吸」は本人が選んだアプリを指定時間に制限するセルフコントロール用アプリです。Family Controls の個人向け許可、Managed Settings の制限画面、Device Activity の予定・再制限・レポートを使用します。スクリーンタイムのデータと設定は端末上で扱い、レポートの利用時間はレポート拡張で集計します。アプリ独自のログインは不要です。

## 無料とPro

無料で、選んだアプリの利用時間レポート（Appleのスクリーンタイムによる日別・週合計と初週との比較）、1件の制限予定、今日の「開かずに戻る」回数、集中時間、厳格モード、ウィジェットを利用できます。従来Pro限定だった利用時間レポート、集中時間、厳格モード、ウィジェットは無料に移しました。Proで追加されるのは、アプリが端末上で記録した開かずに戻れた回数の履歴・週比較と連続日数、複数の制限予定、待ち時間と制限画面のメッセージの変更です。Proの週比較は当アプリの「開かずに戻る」操作の記録を使います。Appleのデータや機能の利用に対して課金することはありません。

## シールドのテスト（iOS・iPadOS 17以降の実機）

1. 初回起動で「許可してアプリを選ぶ」を押し、iOSのダイアログで許可します。
2. 「制限するアプリ」の画面で、端末に入っているアプリを個別に1つ選びます。同じ画面の「今から1時間の制限を始める」を押すと制限が始まり、毎日この時間帯に制限する予定が保存されます。
3. ホーム画面から対象のアプリを開き、制限画面で「開かずに戻る」を押します。ホーム画面から「ひと呼吸」を開き、今日の回数が1増えたことを確認します。
4. 対象を再度開き、「10秒待って開く」を押します。10秒以上経ってからもう一度押し、必要に応じて対象アプリを開き直します。制限の予定が続いている間は、約5分後に対象アプリを開くと制限画面が再表示されます。再制限の反映時刻はiOSのコールバックに従います。
5. 無料プランのホームで「利用時間を見る」を押すと利用時間レポートが開きます。スクリーンタイムの記録が反映されると日別・週合計を確認できます。Proの期間終了後も同じ操作で開けます。
6. 無料プランのホームで「予定を追加」を押すとProの購入画面が開きます。月額・年額・買い切り、購入条件、規約とプライバシーポリシー、「購入を復元」を確認できます。購入の確認にはApp Storeの審査用環境をご利用ください。

iOS側でスクリーンタイムの許可が取り消されている場合は、アプリを開き直し、再許可して対象を選び直してください。
