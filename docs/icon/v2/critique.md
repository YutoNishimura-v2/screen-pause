## 候補別 60px ギャップ分析（対 Opal・ScreenZen・Blockin・Apple Screen Time）

### 候補 A：ひと呼吸の柱（`docs/icon/v2/a.svg` / `a.png`）
1. **安っぽさ信号（背景の局所ハイライト斑）**: 第1案では `cy=18%` の放射状 `#ambient` が 60px 縮小時に柱上の淡い楕円斑として見えた → **`fixed`**（全面の極薄縦グラデーション `0.10` に置換し、斑を解消）。
2. **安っぽさ信号（上部ベベルの消失と下端のくすみ）**: 第1案はガラス上端が `#FFFFFF` だったため同色の 7px 内側ベベルが視認できず、下端 `#DCE0FF` も暗めだった → **`fixed`**（上端を `#F6F7FF` にして `#FFFFFF` の 8px 内側ベベルを際立たせ、下端を `#E5E8FF` に引き上げ）。
3. **コントラスト（対 Opal の高コントラスト黒地）**: 黒地の Opal（約 14:1 相当）に比べると、Royal Indigo 上端は `5.84:1` でやや柔らかい → **`remaining`**（アプリの `.tint(.indigo)` との統一感を優先した色系統固有の差。60px 判読基準 `4.5:1` 以上は確保）。
4. **差別化（対 Screen Time の紫砂時計・メディア停止記号との連想）**: 紫砂時計とはシルエット・青み寄りの Indigo で明確に分離できている一方、二本柱単体は 60px の瞬間視認でメディアの一時停止ボタンに近い → **`remaining`**（アプリ名「ひと呼吸」の直感性と引き換えの記号的親近性）。
5. **60px 判読性（ライト／ダーク／色合い調整）**: 柱幅 `186px`（60px 時 `10.9px`）・中央隙間 `128px`（60px 時 `7.5px`）が 3 モードとも潰れず分離することを確認 → **`fixed`**。

### 候補 B：静かな切れ目（`docs/icon/v2/b.svg` / `b.png`）
1. **判読性・差別化（対 Opal の閉じた輪）**: 第1案の `68°` 開口部は 60px の周辺視で Opal の閉じた五角内孔リングに近かった → **`fixed`**（右上 `-84°〜-6°` の **`78°` 開口** に広げ、60px でも約 14px の明確な切れ目と真円内孔を確保）。
2. **安っぽさ信号（下部金属色の濁りと上部斑）**: 第1案の下端 `#C9D3E3` がやや灰色にくすみ、上部の放射斑が目立った → **`fixed`**（`#2F3443→#0C0E15` の滑らかな縦グラデと `#F5F8FD→#FFFFFF→#DCE4F0` の高輝度プラチナ＋8px 上端ベベルに刷新）。
3. **コントラスト（60px での白黒対比）**: 上 `14.45:1`・中 `15.75:1`・下 `14.37:1` を達成し、ライト・ダーク両壁紙で Opal 並みの視認性を確保 → **`fixed`**。
4. **差別化（対 Screen Time の紫砂時計）**: 黒曜地に開いた真円輪（`55.9% × 55.9%`）であり、色相・輪郭ともに Screen Time との混同余地はゼロ → **`fixed`**。
5. **App Store 棚での色系統被り（対 Opal）**: 同じく黒〜濃灰＋白銀の輪を使う Opal と棚で隣り合うと色面が近い → **`remaining`**（開口部の有無と正円内孔で形状差別化済み。黒系プレミアム案として意図的に維持）。

### 候補 C：呼吸の弧（`docs/icon/v2/c.svg` / `c.png`）
1. **安っぽさ信号・コントラスト（上端水色の白飛び）**: 第1案の `#4DA7FF` 上端では対比 `3.61:1` に落ち、60px で弧の上端が甘かった → **`fixed`**（Ocean Blue `#2A7EE0→#1554BA→#0B307A` へ深め、上 `5.37:1`・中 `6.69:1`・下 `7.72:1` へ改善）。
2. **判読性（60px 中央くびれの詰まり）**: 第1案の中央隙間 `96px`（60px 時 `5.6px`）は縮小時のアンチエイリアスでやや狭かった → **`fixed`**（中心間隔を **`112px`**＝60px 時 `6.6px` に拡張し、60px 縮小図でも明瞭な縦溝を確認）。
3. **差別化（対 Screen Time の砂時計連想）**: 砂時計のくびれを思わせる双弧構造のため、60px で遠くから見ると時間の絞りを連想させる → **`remaining`**（上下の横棒や鋭角を排した開端の双弧＋Ocean Blue の色相で Screen Time の紫砂時計とは別物として成立）。
4. **安っぽさ信号（平面感・下端くすみ）**: 第1案の `#D4E6FF` 下端と不可視ベベルを修正し、`#F4F9FF→#FFFFFF→#DFECFF` と 8px 内側上端ベベルで立体感を付与 → **`fixed`**。
5. **ダークモード視認性（対 ScreenZen）**: ScreenZen の濃紺＋平塗りペリウィンクルに対し、ダーク背景上で発光感のある Ocean Blue グラデーションを維持 → **`fixed`**。

### 候補 D：静寂のしずく（`docs/icon/v2/d.svg` / `d.png`）
1. **安っぽさ信号・コントラスト（第1案の重大な低対比）**: 第1案の明るいミント上端 `#35C9B3` では球上部の対比が `2.85:1` まで低下し、60px で上端が背景に溶けていた → **`fixed`**（深い翡翠ティール `#1B9882→#0E6B5F→#07453F` へ刷新し、上部 `4.70:1`・下部 `7.17:1` を確保）。
2. **安っぽさ信号（球上部の放射ハロー）**: 第1案で球の上に出ていた放射グラデのぼやけを撤去し、純粋な縦グラデーションへ修正 → **`fixed`**。
3. **判読性（60px での点と受け弧の分離）**: 最短離隔 `139.3px`（60px 時 `8.2px`）、球径 `216px`（`12.7px`）、弧太さ `120px`（`7.0px`）で縮小時も癒着ゼロ → **`fixed`**。
4. **差別化（対 Screen Time・Opal・ScreenZen）**: 翡翠ティール＋浮遊する点と受け弧（`51.4% × 51.6%`）は、紫砂時計・黒輪・三段小石のいずれとも被らない独自の落ち着いた造形 → **`fixed`**。
5. **モノクロ高対比勢との差**: 候補 B（`14.45:1`）や候補 A（`5.84:1`）に比べると上端対比 `4.70:1` はやや穏やか → **`remaining`**（穏やかな翡翠系特有の柔らかさであり、`4.5:1` 以上の明瞭さは確保）。

## 推奨案

- **推奨: 候補 B（静かな切れ目）** — 60px 比較で最高水準の明暗対比（14.45–15.75:1）と Screen Time の紫砂時計と全く被らない「開いた輪」の造形を備え、ライト・ダーク両壁紙およびダーク／色合い調整モードすべてで最も高級感と瞬間視認性が高いため。
